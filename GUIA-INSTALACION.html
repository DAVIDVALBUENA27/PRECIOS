🏷️ Etiquetas Góndola

Guía de instalación en PC nuevo

PASO A PASO COMPLETO
💡

Antes de empezar: Necesitas conexión a internet durante todo el proceso de instalación. Una vez instalado, la app también requiere internet para conectarse a la base de datos.

💾

Archivo en tu USB: .env.local

Tienes que copiar este archivo desde la USB a la carpeta del proyecto (PRECIOS\.env.local) antes de iniciar la app. Sin ese archivo la app no se conecta.

1
Instalar Node.js
Solo la primera vez
A
Abrir el navegador y entrar a:
nodejs.org
B
Descargar el botón verde que dice "LTS"

Ej: Node.js 22.x.x LTS — ese, el recomendado.

C
Instalar con todas las opciones por defecto

Siguiente → Siguiente → Instalar → Finalizar.

2
Instalar Git
Solo la primera vez
A
Ir a:
git-scm.com/download/win
B
Descargar e instalar

Todo con las opciones por defecto. Siguiente hasta el final.

3
Descargar el proyecto
Solo la primera vez
A
Abrir la terminal de Windows

Presionar Windows + R, escribir cmd y Enter.

B
Escribir estos comandos uno a uno:
# Ir al escritorio
cd %USERPROFILE%\Desktop

# Descargar el proyecto de GitHub
git clone https://github.com/DAVIDVALBUENA27/PRECIOS.git

# Entrar a la carpeta
cd PRECIOS
4
Copiar el archivo de configuración
Desde la USB
A
Conectar la USB al PC
B
Copiar el archivo .env.local desde la USB

Pegarlo dentro de la carpeta PRECIOS que quedó en el Escritorio.
La ruta completa debe quedar:
Escritorio\PRECIOS\.env.local

C
⚠️ Nota sobre archivos ocultos

Si el archivo no se ve en el Explorador de Windows, activar Ver → Elementos ocultos desde la barra de menú.

5
Iniciar la aplicación
Cada vez que la quieras usar
⭐
Doble clic en iniciar-app.bat

Está dentro de la carpeta PRECIOS en el Escritorio.
La primera vez instala todo automáticamente (2-3 min). Las siguientes abre directo.

B
El navegador se abre solo en: http://localhost:3000

Si no abre automáticamente, escríbelo en la barra de dirección del navegador.

C
Para cerrar la app:

Cerrar la ventana negra (terminal) que se abrió con el bat.

💡
Notas importantes
🌐 Internet La app necesita conexión a internet. Los datos están en la nube.
🔑 Login Usar el mismo correo y contraseña de siempre.
🔄 Actualizaciones Para recibir mejoras: abrir cmd en la carpeta PRECIOS y escribir:
git pull y luego npm run build
🖨️ Imprimir En el diálogo de impresión: usar escala 100% (no "ajustar a página").
❓ Problemas Si algo no carga: cerrar la ventana negra, borrar la carpeta .next dentro de PRECIOS, y volver a abrir el bat.
🎉

¡Listo! Ya tienes Etiquetas Góndola funcionando.
